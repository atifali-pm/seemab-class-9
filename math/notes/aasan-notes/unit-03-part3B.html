🔗 1. Associative properties (p52, p53)

📖 Kitab ke do laws, exam mein bilkul yehi likhna hai
Associative Property of Union: (A ∪ B) ∪ C = A ∪ (B ∪ C)
Associative Property of Intersection: (A ∩ B) ∩ C = A ∩ (B ∩ C)

Teen sets par ek hi operation lag raha ho, to bracket chahe pehle do par lagao ya aakhri do par, jawab bilkul wohi nikalta hai. Bracket sirf yeh tay karta hai ke kaam ka order kya hoga, natija nahin badalta. Is liye hum A ∪ B ∪ C bina bracket ke bhi likh dete hain.

Proof: Associative Property of UnionProof: Associative Property of Intersection
  • Let  x ∈ (A ∪ B) ∪ C
  • ⇒ x ∈ (A ∪ B)  or  x ∈ C
  • ⇒ (x ∈ A or x ∈ B) or x ∈ C
  • ⇒ x ∈ A or (x ∈ B or x ∈ C)
  • ⇒ x ∈ A  or  x ∈ (B ∪ C)
  • ⇒ x ∈ A ∪ (B ∪ C)
  • ⇒ (A ∪ B) ∪ C ⊆ A ∪ (B ∪ C)  (a)
  • Similarly, A ∪ (B ∪ C) ⊆ (A ∪ B) ∪ C  (b)
  • From (a) and (b): (A ∪ B) ∪ C = A ∪ (B ∪ C)
  • Let  y ∈ (A ∩ B) ∩ C
  • ⇒ y ∈ A ∩ B  and  y ∈ C
  • ⇒ (y ∈ A and y ∈ B) and y ∈ C
  • ⇒ y ∈ A and (y ∈ B and y ∈ C)
  • ⇒ y ∈ A  and  y ∈ (B ∩ C)
  • ⇒ y ∈ A ∩ (B ∩ C)
  • ⇒ (A ∩ B) ∩ C ⊆ A ∩ (B ∩ C)  (a)
  • Similarly, A ∩ (B ∩ C) ⊆ (A ∩ B) ∩ C  (b)
  • From (a) and (b): (A ∩ B) ∩ C = A ∩ (B ∩ C)

Poora proof likhte waqt dono taraf sabit karni parti hain: pehle LHS ⊆ RHS, phir RHS ⊆ LHS. Ek set doosre ke barabar tabhi hota hai jab har ek doosre ka subset ho. Sirf (a) likh dena aadha jawab hai.

✏️ Example 8 (p52, p53), Venn verification of union U = {1, 2, 3, 4, 5, …, 15}, A = {2, 4, 6, 8, 10}, B = {1, 2, 3, 4, 5, 6, 7}, C = {2, 3, 5, 7, 11}.
LHS: A ∪ B = {1,2,3,4,5,6,7,8,10}, so (A ∪ B) ∪ C = {1,2,3,4,5,6,7,8,10,11}
RHS: B ∪ C = {1,2,3,4,5,6,7,11}, so A ∪ (B ∪ C) = {1,2,3,4,5,6,7,8,10,11}
Dono Venn diagrams mein same region is shaded, is liye law verified. Bahar reh gaye 9, 12, 13, 14, 15.
✏️ Example 9 (p53), Venn verification of intersection U = {1, 2, 3, …, 11}, A = {1, 2, 3, 5, 7, 9}, B = {1, 2, 3, 4, 5, 6}, C = {5, 6, 7, 8}.
LHS: A ∩ B = {1, 2, 3, 5}, so (A ∩ B) ∩ C = {5}  ·  RHS: B ∩ C = {5, 6}, so A ∩ (B ∩ C) = {5}
Intersection mein hamesha chhota jawab aata hai; teeno circles ka beech wala hissa hi shade hoga.

📤 2. Distributive properties (p54, p55)

📖 Kitab ke do laws
(a) Union over Intersection: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
(b) Intersection over Union: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

Yahan do alag operations hain, is liye bracket ab bekaar nahin. Bahar wala set bracket ke dono members par baant diya jata hai, theek jaise numbers mein a(b + c) = ab + ac hota hai. Farq sirf itna ke numbers mein multiplication hi addition par distribute hota hai, ulta nahin; sets mein dono taraf chalta hai, union bhi aur intersection bhi. Baantne ke baad bahar wala operation andar chala jata hai aur andar wala bahar aa jata hai, yaani ∪ aur ∩ apni jagah badal lete hain.

Proof (a): Union over IntersectionProof (b): Intersection over Union
  • Let  x ∈ A ∪ (B ∩ C)
  • ⇒ x ∈ A  or  x ∈ (B ∩ C)
  • ⇒ x ∈ A or (x ∈ B and x ∈ C)
  • ⇒ (x ∈ A or x ∈ B) and
        (x ∈ A or x ∈ C)
  • ⇒ x ∈ (A ∪ B) and x ∈ (A ∪ C)
  • ⇒ x ∈ (A ∪ B) ∩ (A ∪ C)
  • ⇒ A ∪ (B ∩ C) ⊆ (A ∪ B) ∩ (A ∪ C)  (a)
  • Again, let y ∈ (A ∪ B) ∩ (A ∪ C)
  • ⇒ … ⇒ y ∈ A ∪ (B ∩ C)
  • ⇒ (A ∪ B) ∩ (A ∪ C) ⊆ A ∪ (B ∩ C)  (b)
  • Let  x ∈ A ∩ (B ∪ C)
  • ⇒ x ∈ A  and  x ∈ (B ∪ C)
  • ⇒ x ∈ A and (x ∈ B or x ∈ C)
  • ⇒ (x ∈ A and x ∈ B) or
        (x ∈ A and x ∈ C)
  • ⇒ x ∈ (A ∩ B) or x ∈ (A ∩ C)
  • ⇒ x ∈ (A ∩ B) ∪ (A ∩ C)
  • ⇒ A ∩ (B ∪ C) ⊆ (A ∩ B) ∪ (A ∩ C)  (a)
  • Again, let y ∈ (A ∩ B) ∪ (A ∩ C)
  • ⇒ … ⇒ y ∈ A ∩ (B ∪ C)
  • ⇒ (A ∩ B) ∪ (A ∩ C) ⊆ A ∩ (B ∪ C)  (b)

Dono taraf From (a) and (b) likh kar barabari ka nishan lagta hai. Chauthi line hi asal chaal hai: or ke andar se and bahar nikal aata hai (aur doosre proof mein and ke andar se or).

✏️ Example 10 (p55), dono laws Venn se verify U = {x : x ∈ W ∧ x ≤ 12} = {0, 1, 2, …, 12}, A = {x : x ∈ W ∧ x ≤ 4} = {0, 1, 2, 3, 4}, B = {3, 4, 5, 6, 7}, C = {6, 7, 8, 9}.
(a) B ∩ C = {6, 7} ⇒ A ∪ (B ∩ C) = {0,1,2,3,4,6,7}.
A ∪ B = {0,1,2,3,4,5,6,7} and A ∪ C = {0,1,2,3,4,6,7,8,9} ⇒ (A ∪ B) ∩ (A ∪ C) = {0,1,2,3,4,6,7}. Verified.
(b) B ∪ C = {3,4,5,6,7,8,9} ⇒ A ∩ (B ∪ C) = {3, 4}.
A ∩ B = {3, 4} and A ∩ C = φ ⇒ (A ∩ B) ∪ (A ∩ C) = {3, 4}. Verified.
Example 10 ka naqsha: A aur B kat-te hain, B aur C kat-te hain, magar A ∩ C = φ.
⚠️ Kitab ki do ghaltiyan, in par dhoka mat khana 1. Example 10 mein C ki shart {z : z ∈ N ∧ 3 ≤ z ≤ 7} chhapi hai, jo bilkul B jaisi hai. Naqsha saaf batata hai ke C = {6, 7, 8, 9}, yaani shart 6 ≤ z ≤ 9 honi chahiye. Venn diagram ko sach maano.
2. Associative union ke proof ki step (b) mein ek bracket chhoot gaya hai: A ∪ B ∪ C) ⊆ (A ∪ B) ∪ C. Sahi likhai hai A ∪ (B ∪ C) ⊆ (A ∪ B) ∪ C.
⭐ Key Fact box (p56), yahan se sawal bante hain (a) A = {0, 1, 3, 5, 7}, B = {x | x ∈ N ∧ x ≤ 5} and C = {1, 2, 3, 4, 6, 12}: find (A ∪ B) ∩ C using Venn diagrams.
(b) A = {0, 2, 4, 6}, B = {1, 3, 5, 7} and C = {1, 2, 3, 6}: find (A ∩ B) ∩ C, A ∩ (B ∩ C) and (A ∪ B) ∩ C using Venn diagram.
🧠 Pakki trick Sab se aam ghalti: (A ∪ B) ∩ C ko A ∪ (B ∩ C) samajh lena. Yaad rakho (A ∪ B) ∩ C ≠ A ∪ (B ∩ C), kyunke operations alag hain. Usool yaad rakho: ek jaisa operation to bracket azad, alag operations to bracket pakka. Ab Exercise 3.1 ke Q3 se Q7 khud karo.
