📦 1. Set kya hai (p46)

📖 Kitab ki definition, exam mein bilkul yehi English likhni hai A set is a well-defined collection of distinct objects.
The term well-defined means that the objects follow a given discipline with which presence or absence of some object in the set is checked.

Well-defined ka matlab: koi jhagra na rahe. "Halke patharon ka collection" set nahin hai, kyunke halka aur bhari har banda apni marzi se decide karega. "1 kg se kam wazan ke patharon ka collection" well-defined hai, kyunke tarazu faisla kar deta hai. Ek set mein alag alag qism ki cheezein bhi aa sakti hain, jaise library ke books, chairs, keys aur locks.

✏️ Example 1 (p46) Prime aur even dono = {2} · Pakistani currency = {5, 10, 20, 50, 100, 500, 1000, 5000} · lafz ‘set’ ke huroof = {s, e, t} · 1 se chhote natural numbers = { } · 3, −9, 2, 3, 4, 2 mein se natural numbers = {2, 3, 4}. Aakhri wala yaad rakho: repeat honay wala element sirf ek dafa likha jata hai.

📝 2. Set-builder form (rule method) (p47)

📖 Notation aur uski reading Yahan saray elements ginte nahin, balke un ka rule likhte hain. A = {x | x ∈ Z} ko parha jata hai: A is the set of all elements x such that x belongs to Z. Seedhi lakeer | = "such that", aur ∧ = "and".

🔢 3. Most commonly used sets of numbers (p48)

N = Natural numbers{1, 2, 3, 4, …}P = Prime numbers{2, 3, 5, 7, 11, 13, …}
W = Whole numbers{0, 1, 2, 3, 4, …}Q = Rational numbers{p/q | p, q ∈ Z ∧ q ≠ 0}
Z = Integers{0, ±1, ±2, ±3, …}Q′ = Irrational numbers{x | x ≠ p/q, p, q ∈ Z ∧ q ≠ 0}

⭐ Key Fact box (p49), yahan se MCQ banti hai
  • The common elements of A and B are written once.
  • Two sets A and B are said to be disjoint, if A ∩ B = φ
  • The elements of A are never present in Ac and vice versa.
  • Two sets are said to be overlapping, if neither set is subset of the other and their intersection is non-empty.

📖 Venn diagram banane ka tareeqa (p50) The pictorial representation of the relationship A ⊂ U is called a Venn diagram. In a Venn diagram, universal set is represented by the interior of the rectangle, however inside the rectangle, the subsets are represented by the interior of any other closed shape like circles or ovals etc.

3️⃣ 6. Teen sets ka union aur intersection (p50, p51, p52)

🧠 Bracket ka usool, sab se ahem baat Kitab: We use brackets to separate two sets from the third one because these represent different sets. Pehle bracket ke andar wala kaam karo, phir us ka teesre set ke saath. Is liye (A ∪ B) ∩ C aur A ∪ (B ∩ C) bilkul alag cheezein hain.
✏️ Example 5 (p51): A = {0,1,2,3,4}, B = {3,4,5,6}, C = {6,7,8,9} B ∩ C = {6}, to A ∪ (B ∩ C) = {0,1,2,3,4,6}.   B ∪ C = {3,4,5,6,7,8,9}, to A ∩ (B ∪ C) = {3, 4}.
✏️ Example 6 (p51), disjoint ka case: P = {a,b,c,d,e}, Q = {f,g,h,i}, R = {d,e,f,g,j} P ∪ Q = {a,b,c,d,e,f,g,h,i}, to (P ∪ Q) ∩ R = {d,e,f,g}.   P aur Q disjoint hain (P ∩ Q = φ), to (P ∩ Q) ∪ R = {d,e,f,g,j}.
✏️ Example 7 (p51, p52), subset ka case: P = {3,5,7}, Q = {1,3,5,7,9}, R = {0,2,5,8} P ⊂ Q hai, is liye P ka circle Q ke andar banega. Q ∩ R = {5}, to P ∪ (Q ∩ R) = {3, 5, 7}.
Teen overlapping sets ka standard Venn. Rectangle = U, beech ka chhota hissa A ∩ B ∩ C. Shade karne se pehle poora naqsha banao, phir maanga gaya hissa bharo.
