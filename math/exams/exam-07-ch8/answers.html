SECTION A — MCQ Answer Key (12 Marks)
# Ans Correct Option Explanation
1 A rise ÷ run Gradient = vertical distance / horizontal distance = rise/run = tanθ. Option B inverts the fraction; C multiplies instead of divides; D adds them, which is meaningless.
2 C 0 A horizontal line has inclination θ = 0°, so gradient m = tan 0° = 0. A vertical line has undefined gradient. Distractors 1 and −1 belong to lines inclined at 45° and 135° respectively.
3 D m1 × m2 = −1 For perpendicular lines, m1 × m2 = −1 (product of slopes is negative one). Equal slopes (A) means parallel. Sum zero (B) is incorrect. Product +1 (C) is a common misconception.
4 A y = mx + c The slope-intercept form is y = mx + c, where m is the slope and c is the y-intercept. Option B is point-slope form; C is two-intercept form; D is general form.
5 A 6/5 For ax + by + c = 0, slope = −a/b. Here 6x − 5y + 15 = 0, so slope = −(6)/(−5) = 6/5. Option B gives the negative, confusing the sign; C and D invert the ratio.
6 B x = 3 A line parallel to the y-axis has equation x = constant. Through (3, 5) that constant is 3, giving x = 3. A line y = 5 would be parallel to the x-axis. Common error: confusing which coordinate gives the constant.
7 A 5 The x-intercept is found by setting y = 0: x + 0 = 5, so x = 5. Students often confuse x-intercept (set y = 0) with y-intercept (set x = 0), giving −5 or 1 as errors.
8 A (m2−m1) / (1+m1m2) The angle from l1 to l2 uses tanθ = (m2−m1) / (1+m1m2). Option B has addition in numerator and subtraction in denominator (both wrong). Options C and D are incorrect forms.
9 B Slope of AB = slope of BC Three points are collinear if and only if slopes of any two segments joining them are equal. Option A (unequal slopes) means non-collinear. Option C mixes lengths with slopes. Option D means perpendicular.
10 C Length of perpendicular from origin In the normal form x cosα + y sinα = p, the value p is the length of the perpendicular from the origin to the line. It is always positive. Confusing it with slope or intercept is a common error.
11 B x-axis The equation y = 0 means every point on the line has y-coordinate zero, which is the definition of the x-axis. The y-axis is x = 0. This is directly from Miscellaneous Exercise 8 of the textbook.
12 A (0, 0) Both equations 9x − 7y = 0 and 8x − 11y = 0 pass through the origin (substituting x = 0, y = 0 satisfies both). Any two lines passing through the origin intersect there. Directly from Miscellaneous Exercise 8.

2(i) 3 marks
Find the gradient of line whose inclination is 120°.
Gradient = tan θ = tan 120° 1 mark
tan 120° = tan(180° − 60°) = −tan 60° = −√3 ≈ −1.732 1 mark
The gradient is negative because 90° < 120° < 180°, and tan is negative in the second quadrant. Lines making obtuse angles with the positive x-axis have negative gradients. 1 mark
OR

m = tanθ = −1.732 1 mark
θ = tan−1(−1.732) 1 mark
Since −1.732 ≈ −√3 = −tan 60°, therefore θ = 180° − 60° = 120° 1 mark

Step 1: Find slopes of all three sides 2 marks

Conclusion: Since slope(AB) × slope(AC) = −1, lines AB and AC are perpendicular. The right angle is at vertex A(3, −1). 1 mark
