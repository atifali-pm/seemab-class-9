SECTION A — MCQ Answer Key (12 × 1 = 12 Marks)
# Ans Correct Option Explanation
1 B k(a + b + c) The common factor k is taken out from each term: ka + kb + kc = k(a + b + c). This is the basic common factor type of factorization (Type recalled from previous grades).
2 C (a + b)(a − b) This is the standard difference of two squares identity: a2 − b2 = (a + b)(a − b). Both binomials are factors; squaring option A gives a2 + 2ab + b2, which is wrong.
3 B (a2 + ab + b2)(a2 − ab + b2) By adding and subtracting a2b2: a4 + a2b2 + b4 = (a2 + b2)2 − (ab)2, which factors as (a2 + ab + b2)(a2 − ab + b2). This is the Type-I factorization form from Section 4.1.
4 A (x − 1)(x − 8) Splitting the middle term: x2 − 9x + 8 = x2 − x − 8x + 8 = x(x−1) − 8(x−1) = (x−1)(x−8). Product = 8, sum = 9, both negative, so factors −1 and −8.
5 C (a + b)(a2 − ab + b2) The sum of two cubes identity is: a3 + b3 = (a + b)(a2 − ab + b2). Note the middle sign inside the trinomial is negative (−ab), which distinguishes it from Option A.
6 B (a + b)3 The perfect cube expansion: (a + b)3 = a3 + 3a2b + 3ab2 + b3. This is the Type-IV form studied in Section 4.1 using the binomial cube identity.
7 C Highest power of every factor Per the textbook Key Fact (Section 4.3): HCF uses the lowest power of common factors, while LCM uses the highest power of every factor (both common and uncommon) that appears in any polynomial.
8 B P × Q ÷ H From the relation proved in Section 4.3.2: LCM × HCF = P × Q, so LCM = (P × Q) ÷ HCF. This is the fundamental HCF-LCM relationship used throughout the chapter.
9 C Q ≠ 0 An algebraic fraction P/Q is defined only when the denominator Q is non-zero (Q ≠ 0), just as in arithmetic fractions. Division by zero is undefined in mathematics.
10 A ±(2a + 3b) 4a2 + 12ab + 9b2 = (2a)2 + 2(2a)(3b) + (3b)2 = (2a + 3b)2. Applying square root gives ±(2a + 3b). The Key Fact (Section 4.5) states square roots always come in additive inverse pairs.
11 B LCM of denominators Section 4.4.4 states: algebraic fractions with different denominators are added by finding the LCM of the denominators (the common denominator), then combining numerators. HCF of denominators would give too small a value.
12 C Multiplication Section 4.1 explicitly states: "the factorization process is essentially the opposite of the multiplication process." Multiplying factors gives the polynomial; factorizing the polynomial recovers the factors.

Q. 2(i) 3 marks
Factorize: 2x2y3 − 6x2y2 + 2xy3
2x²y³ − 6x²y² + 2xy³ = 2xy²(xy − 3x + y) [take out HCF = 2xy²] [1 mark] = 2xy²(xy + y − 3x) [rearrange] = 2xy²[y(x + 1) − 3x] [group: y is common in first two] [1 mark] ∴ 2x²y³ − 6x²y² + 2xy³ = 2xy²(xy + y − 3x) [1 mark]
OR
Factorize by grouping: 3nx − 3x − 3ny + 3y
3nx − 3x − 3ny + 3y = 3(nx − x − ny + y) [take out common factor 3] [1 mark] = 3[x(n − 1) − y(n − 1)] [group: (n−1) is common] [1 mark] = 3(n − 1)(x − y) [1 mark]
Q. 2(ii) 3 marks
Factorize: x2 − 6ax + 9a2 − 16b2
x² − 6ax + 9a² − 16b² = (x² − 6ax + 9a²) − 16b² [group first three terms] [1 mark] = (x − 3a)² − (4b)² [perfect square trinomial] [1 mark] = (x − 3a + 4b)(x − 3a − 4b) [difference of squares] [1 mark]
OR
Factorize: 1 − x2 − 2xy − y2
1 − x² − 2xy − y² = 1 − (x² + 2xy + y²) [group last three terms] [1 mark] = 1 − (x + y)² [perfect square] [1 mark] = [1 + (x + y)][1 − (x + y)] = (1 + x + y)(1 − x − y) [difference of squares] [1 mark]

OR
Factorize: m4 + m2 + 1
m⁴ + m² + 1 = (m²)² + m² + 1 Add and subtract m²: [1 mark] = (m²)² + 2m² + 1 − m² = (m² + 1)² − (m)² [difference of squares] [1 mark] = (m² + 1 + m)(m² + 1 − m) = (m² + m + 1)(m² − m + 1) [1 mark]

Q. 2(vii) 3 marks
Find the HCF of: (x + y)2 and x2 − y2
Factorize each expression: (x + y)² = (x + y)(x + y) [complete factored form] [1 mark] x² − y² = (x + y)(x − y) [difference of squares] [1 mark] Common factor with least power = (x + y)¹ ∴ HCF = (x + y) [1 mark]
OR
Find the HCF of: (a − b)3 and a2 − 2ab + b2

Q. 2(viii) 3 marks
Find the HCF of: ax2 + 7ax + 12a,  ax2 − 5ax − 24a  and  2ax2 + 5ax − 3a
Factor each: ax² + 7ax + 12a = a(x² + 7x + 12) = a(x+3)(x+4) [1 mark] ax² − 5ax − 24a = a(x² − 5x − 24) = a(x−8)(x+3) [1 mark] 2ax² + 5ax − 3a = a(2x² + 5x − 3) = a(2x−1)(x+3) Common factors with least power: a¹ and (x+3)¹ ∴ HCF = a(x + 3) [1 mark]
OR
Find the HCF of x2 − 49 and x2 − 4x − 21
x² − 49 = (x + 7)(x − 7) [difference of squares] [1 mark] x² − 4x − 21: factors of −21 with sum −4 → −7 and +3 = (x − 7)(x + 3) [1 mark] Common factor = (x − 7) ∴ HCF = (x − 7) [1 mark]
Q. 2(ix) 3 marks
State LCM × HCF = P × Q. If HCF = x − 7 and LCM = x3 − 10x2 + 11x + 70, find the product of the two polynomials.
Key relation: LCM × HCF = P × Q [1 mark] HCF = (x − 7) LCM = x³ − 10x² + 11x + 70 Product P × Q = LCM × HCF [1 mark] = (x³ − 10x² + 11x + 70)(x − 7) (Simplification not required — the relation gives the product directly) ∴ P × Q = (x − 7)(x³ − 10x² + 11x + 70) [1 mark]
OR
Find the LCM of: x2 + x − 6,  x2 + x − 2  and  x2 − 4x + 3
Factorize each: x² + x − 6 = (x + 3)(x − 2) [1 mark] x² + x − 2 = (x + 2)(x − 1) Wait — let me verify: x² + x − 6: need sum +1, product −6 → +3 and −2 ✓ x² + x − 2: sum +1, product −2 → +2 and −1 ✓ x² − 4x + 3: sum −4, product +3 → −3 and −1 → (x−3)(x−1) [1 mark] All factors: (x+3), (x−2), (x+2), (x−1), (x−3) LCM = product of all distinct factors (each to highest power) ∴ LCM = (x + 3)(x + 2)(x − 1)(x − 2)(x − 3) [1 mark]
Q. 2(x) 3 marks
Simplify: (x2 − 1)/(x2 + 4x + 4) × (x + 2)/(x2 + 2x − 3)
Step 1: Factorize all numerators and denominators: x² − 1 = (x+1)(x−1) x² + 4x + 4 = (x+2)(x+2) x + 2 = (x+2) x² + 2x − 3 = (x+3)(x−1) [1 mark] Step 2: Write as one fraction and cancel: = [(x+1)(x−1)] / [(x+2)²] × (x+2) / [(x+3)(x−1)] = [(x+1)(x−1)(x+2)] / [(x+2)²(x+3)(x−1)] [1 mark] = (x+1) / [(x+2)(x+3)] ∴ Result = (x + 1) / (x² + 5x + 6) [1 mark]
OR

= (r² − s²)/r × s/(r − s) [invert divisor] [1 mark] = [(r+s)(r−s)] / r × s/(r−s) [factorize r²−s²] [1 mark] = s(r+s) / r [cancel (r−s)] ∴ Result = (sr + s²) / r [1 mark]

Find the square root of 4a2 + 12ab + 9b2 by factorization method.
4a² + 12ab + 9b² = (2a)² + 2(2a)(3b) + (3b)² [identify perfect square form] [1 mark] = (2a + 3b)² [complete square] [1 mark] Applying square root: √(4a² + 12ab + 9b²) = √[(2a + 3b)²] = ±(2a + 3b) [1 mark]

Q. 3(i) 5 marks
Factorize completely: (x2 + 3x − 4)(x2 + 3x + 5) + 8
Observe that the first two terms inside both brackets are identical: x² + 3x Step 1: Let a = x² + 3x [1 mark] Then the expression becomes: (a − 4)(a + 5) + 8 Step 2: Expand: = a² + 5a − 4a − 20 + 8 = a² + a − 12 [1 mark] Step 3: Factorize a² + a − 12: Factors of −12 with sum +1: +4 and −3 = (a + 4)(a − 3) [1 mark] Step 4: Substitute back a = x² + 3x: = (x² + 3x + 4)(x² + 3x − 3) [1 mark] Verify neither factor factorizes further (discriminants < 0 for first): Discriminant of x² + 3x + 4: 9 − 16 = −7 < 0 (irreducible) ✓ ∴ (x² + 3x − 4)(x² + 3x + 5) + 8 = (x² + 3x + 4)(x² + 3x − 3) [1 mark]

Factorize completely: (x + 5)(x + 3)(x + 2)(x + 6) − 88
Step 1: Pair the binomials strategically. Notice: 5 + 3 = 8 and 2 + 6 = 8 (sums are equal) [1 mark] So pair (x+5)(x+3) and (x+2)(x+6): (x+5)(x+3) = x² + 8x + 15 (x+2)(x+6) = x² + 8x + 12 Step 2: Let a = x² + 8x [1 mark] = (a + 15)(a + 12) − 88 Step 3: Expand: = a² + 12a + 15a + 180 − 88 = a² + 27a + 92 [1 mark] Step 4: Factorize a² + 27a + 92: Factors of 92 with sum 27: +4 and +23 = (a + 4)(a + 23) [1 mark] Step 5: Substitute back a = x² + 8x: = (x² + 8x + 4)(x² + 8x + 23) [1 mark] ∴ (x+5)(x+3)(x+2)(x+6) − 88 = (x² + 8x + 4)(x² + 8x + 23)
Q. 3(ii) 5 marks
Find the HCF of P = 2m2 − 2mn,  Q = 4m4 − 4m2n2,  R = 2m3 − 4m2n + 2mn2 by factorization.
Step 1: Factorize P: 2m² − 2mn = 2m(m − n) [1 mark] Step 2: Factorize Q: 4m⁴ − 4m²n² = 4m²(m² − n²) = 4m²(m+n)(m−n) = 2² · m² · (m+n) · (m−n) [1 mark] Step 3: Factorize R: 2m³ − 4m²n + 2mn² = 2m(m² − 2mn + n²) = 2m(m − n)² [1 mark] Step 4: List common factors with LOWEST powers: P = 2 · m · (m−n) Q = 2² · m² · (m+n) · (m−n) R = 2 · m · (m−n)² Common numerical: 2¹ (lowest power of 2) Common variable: m¹ (lowest power of m) Common binomial: (m−n)¹ (lowest power of m−n) [1 mark] ∴ HCF = 2m(m − n) [1 mark]
OR
Find the HCF of P = x3 + x2 − 5x + 3 and Q = x2 + 3x by the division method.
Step 1: P has higher degree; use Q = x² + 3x as divisor. Note: x² + 3x = x(x + 3), degree 2; P degree 3. [1 mark] Divide P by Q: x³ + x² − 5x + 3 ÷ (x² + 3x) x³ + x² − 5x + 3 −(x³ + 3x²) ───────────── −2x² − 5x + 3 −(−2x² − 6x) ───────────── x + 3 ← remainder R₁ [1 mark] Step 2: Now divide Q by R₁: x² + 3x ÷ (x + 3) = x(x + 3) ÷ (x + 3) [1 mark] = x remainder 0 [1 mark] Since remainder is 0, last divisor = HCF. ∴ HCF = x + 3 [1 mark]
Q. 3(iii) 5 marks
Find the LCM of 2x2 − 12xy + 16y2,  x2 − 6xy + 8y2  and  3x2 − 12y2. Hence verify LCM × HCF = P × Q for the first two.
Step 1: Factorize all three: 2x² − 12xy + 16y² = 2(x² − 6xy + 8y²) = 2(x−4y)(x−2y) [1 mark] x² − 6xy + 8y² = (x−4y)(x−2y) 3x² − 12y² = 3(x²−4y²) = 3(x+2y)(x−2y) [1 mark] Step 2: All distinct factors (with highest powers): 2, 3, (x−4y), (x−2y), (x+2y) LCM = 2 × 3 × (x−4y) × (x−2y) × (x+2y) = 6(x−4y)(x−2y)(x+2y) [1 mark] Step 3: Find HCF of first two (for verification): P = 2(x−4y)(x−2y) Q = (x−4y)(x−2y) Common factors (lowest power): (x−4y)¹(x−2y)¹ HCF = (x−4y)(x−2y) [1 mark] Step 4: Verify LCM × HCF = P × Q: LCM × HCF = 6(x−4y)(x−2y)(x+2y) × (x−4y)(x−2y) = 6(x−4y)²(x−2y)²(x+2y) P × Q = 2(x−4y)(x−2y) × (x−4y)(x−2y) = 2(x−4y)²(x−2y)² These are NOT equal — the LCM in the verification should use only P and Q: LCM of P and Q = 2(x−4y)(x−2y) = P (since P is a multiple of Q) LCM(P,Q) × HCF(P,Q) = 2(x−4y)(x−2y) × (x−4y)(x−2y) = 2(x−4y)²(x−2y)² P × Q = 2(x−4y)(x−2y) × (x−4y)(x−2y) = 2(x−4y)²(x−2y)² ✓ (Both sides equal) [1 mark]
OR
Product of two polynomials is x4 + 3x3 − 12x2 − 20x + 48 and their HCF is x − 2. Find their LCM. Also verify LCM × HCF = P × Q.
Given: P × Q = x⁴ + 3x³ − 12x² − 20x + 48 HCF = x − 2 Step 1: Use LCM = (P × Q) / HCF [1 mark] Step 2: Divide the product by (x − 2): x⁴ + 3x³ − 12x² − 20x + 48 ÷ (x − 2) By synthetic division or long division: x⁴ + 3x³ − 12x² − 20x + 48 −(x⁴ − 2x³) ─────────── 5x³ − 12x² − 20x + 48 −(5x³ − 10x²) ─────────────── −2x² − 20x + 48 −(−2x² + 4x) ───────────── −24x + 48 −(−24x + 48) ───────────── 0 [2 marks] LCM = x³ + 5x² − 2x − 24 [1 mark] Step 3: Verify LCM × HCF = P × Q: LCM × HCF = (x³ + 5x² − 2x − 24)(x − 2) = x⁴ + 3x³ − 12x² − 20x + 48 = P × Q ✓ [1 mark]
