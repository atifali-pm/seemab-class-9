1. Do definitions jo poora chapter chalati hain

Arrhenius concept: Acid woh substance hai jo paani mein ionize ho kar H+ ions deta hai. Base woh hai jo paani mein ionize ho kar OH− ions deta hai.
HCl(g) → H+(aq) + Cl−(aq)   |   NaOH(s) → Na+(aq) + OH−(aq)
Bronsted-Lowry concept: Acid = proton donor (H+ deta hai). Base = proton acceptor (H+ leta hai).
HCl + H2O → H3O+ + Cl−   (HCl = acid, H2O = base, H3O+ = hydronium ion)
H2O + NH3 ⇌ NH4+ + OH−   (yahan H2O acid hai, NH3 base hai)
Arrhenius theory ki limitation: yeh sirf aqueous solutions par lagti hai. Yeh explain nahin kar sakti ke CO2 aur SO2 acidic kyun hain (in mein H hi nahin) aur NH3 base kyun hai (is mein OH hi nahin). Isi liye 1923 mein Bronsted-Lowry theory aayi.
Amphoteric: jo substance acid aur base dono ki tarah react kare. Paani amphoteric hai — kabhi proton deta hai, kabhi leta hai.

2. Strong vs Weak (yeh sirf ionization ke baare mein hai)

Strong acid: paani mein 100% ionize ho jaye. Examples: HCl, HNO3, H2SO4. Single arrow (→) use karo.
Weak acid: poori tarah ionize na ho. Example: ethanoic acid (CH3COOH) jo sirkay (vinegar) mein hota hai, sirf 5% tak ionize hota hai. Reversible arrow (⇌) use karo.
CH3COOH ⇌ H+ + CH3COO−
Strong bases: NaOH, KOH, Ca(OH)2.   Weak bases: Al(OH)3, NH3.

3. Base aur Alkali ka farq (yeh zaroor aata hai)

Bases = metals ke oxides aur hydroxides.   Alkali = woh base jo paani mein ghul jaye (water soluble).
Yani: har alkali ek base hai, lekin har base alkali nahin hai.
Alkali hain: NaOH, KOH, Ca(OH)2.   Alkali nahin hain: Cu(OH)2, Al(OH)3, Fe(OH)3 (yeh paani mein nahin ghulte).
Ghar ki cheezein jin mein alkali hota hai: soap, detergent, shampoo, toothpaste.

4. Acids ki 5 properties (equations yaad karo)

1. Taste khatta (sour).   2. Blue litmus ko red kar dete hain.
3. Metal ke saath:   Metal + Acid → Salt + Hydrogen gas
Zn + 2HCl → ZnCl2 + H2   |   Mg + H2SO4 → MgSO4 + H2
4. Metal carbonate ke saath:   Metal carbonate + Acid → Salt + Water + Carbon dioxide
Na2CO3 + 2HCl → 2NaCl + H2O + CO2   |   CaCO3 + H2SO4 → CaSO4 + H2O + CO2
5. Base ke saath (neutralization):   Acid + Base → Salt + Water
HCl + NaOH → NaCl + H2O   |   H2SO4 + 2KOH → K2SO4 + 2H2O

5. Bases ki 5 properties

1. Taste karwa (bitter).   2. Red litmus ko blue kar dete hain.   3. Solution chhoone par slippery lagta hai.
4. Acids ko neutralize karte hain → salt + water.
H2SO4 + 2NaOH → Na2SO4 + 2H2O
5. Garam karne par ammonium salts ko decompose karte hain aur ammonia gas nikalti hai.
NaOH + NH4Cl → NaCl + NH3 + H2O   |   KOH + NH4Cl → KCl + NH3 + H2O

6. Oxides aur Hydroxides

Metal + Oxygen → Metal oxide    4Na + O2 → 2Na2O  |  2Mg + O2 → 2MgO
Metal oxide + Water → Metal hydroxide
MgO + H2O → Mg(OH)2  |  Na2O + H2O → 2NaOH  |  CaO + H2O → Ca(OH)2
Amphoteric oxides/hydroxides: jo acid aur base dono ke saath react karte hain — Al2O3, Al(OH)3, ZnO, Zn(OH)2.

7. Acid Rain

Normal baarish pehle se halki si acidic hoti hai kyunki us mein hawa ki CO2 ghul jaati hai. Insani activity se bohat saray acid oxides hawa mein chale jaate hain, jo baarish ko bohat zyada acidic bana dete hain — isay acid rain kehte hain.
Acid rain mein ghula hua hota hai: nitric acid (HNO3) aur sulphuric acid (H2SO4).
Nuqsan: acids corrosive hote hain, is liye acid rain buildings, structures aur statues ko kha jaati hai — khaas taur par woh jin mein metals aur metal carbonates (marble, limestone) hote hain.
